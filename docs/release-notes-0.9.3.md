# 声键 0.9.3 发布说明

日期：2026-11-17

> 本文件在 `v0.9.3` tag 推送时由 release workflow 逐字发布（`body_path`）。

## ⚠️ 不兼容更新：后台组件改名，需要点一次「更新」

这一版把后台组件从 `rc003-helper` 改名为 `hid-host`（它早已不只服务于 RC003：三款遥控器、
按键合成、虚拟键盘、驱动管理都在里面）。因为计划任务名、资源目录、运行时目录都变了，
**旧版助手不会被自动替换**。

升级后：

1. 首次打开应用，连接页会出现一条提示：「这次更新与旧的后台组件不兼容…」；
2. 到 **设置 → 音频及语音 → 遥控器 → 全按键支持服务** 点一次「**更新**」，按提示通过一次 UAC；
3. 提示自动消失，服务恢复。

迁移是自动的（不需要手工清理）：

- 新任务 `Shengjian HID Host` 注册后，旧任务 `Shengjian RC003 Helper` 会被删除；
- 旧资源目录 `resources/rc003/`、旧运行时目录 `%ProgramData%\Shengjian\rc003-helper` 会被清理
  （旧助手进程还占着文件时会留到下次启动再清）；
- **不受影响**：已装好的虚拟键盘驱动、全部设置项、按键方案、宏、热键配置。

如果更新后遥控器按键没反应，通常是宿主里还挂着旧世代的注入模块：重启一次系统即可
（这是换代的既有约束，不是本版引入的问题）。

## 新增：虚拟键盘后端（三键 / 任意组合）

遥控器的按键报告有个物理限制：**每帧最多两个键**。所以 `Ctrl+Shift+Alt`、`Alt+W` 这类组合
以前发不出去，表现为「按了语音键，输入法没反应」。

本版增加第二条发键通道：后台组件通过 WinUHid 创建一台**虚拟键盘**，绕过报告层限制。

- 设置 → 音频及语音 → 遥控器 → **虚拟键盘（三键 / 任意组合）**：显示 `可用` / `未安装`，
  可在这里一键安装或卸载驱动（由后台组件以管理员身份执行，**不需要再单独确认 UAC**）；
- 没装驱动时功能自动回落（先报告层、再注入），不会因为缺驱动而不可用；
- 热键超过两个键且后端不可用时，热键下方会直接提示该怎么装，而不是让用户按了没反应再来查。

真机验证：`Ctrl+Shift+Alt` 经虚拟键盘发出，低级键盘钩子见三键同帧到达且
`flags=0x0`（非注入），Chatterfly 正常弹出语音条并出字。
