# 声键 0.9.2 发布说明

日期：待发布

> 本文件在 `v0.9.2` tag 推送时由 release workflow 逐字发布（`body_path`）。

本版是 0.9.1 之后的修复版，共两处行为变化。

## 修复：切换输入工具后语音热键不跟着换

设置页里换了「输入法」之后，上一个工具的自定义语音热键会继续留在界面上，并继续
下发给新工具——表现是「设置里看着配好了，遥控器按了没反应」。

- 现在换工具会把自定义热键重置为该工具的默认预设（工具专属，旧组合通常不适用）；
- 同一工具重新选中不会清空已配置的热键；
- 设备级覆盖输入法时，热键那一栏改为显示**实际生效工具**的默认键，不再显示错工具的。

## 变更：Chatterfly 不再预置默认热键

Chatterfly 只认报告层的真实按键，而报告层能表达的组合受器件与白名单限制。原先预置的
`Ctrl+Win` 不在白名单内，**注定按不出来**，等于给了个假的“默认可用”。

- 现在 Chatterfly 的默认热键为空，设置页显示「未设置快捷键」；
- 首次选择 Chatterfly 后，请点「配置」选一个组合；**实测可用 `Ctrl+Alt`**（左 Ctrl + 左 Alt），
  或单键 `右 Alt`；
- 不配置也不会报错，只是遥控器语音键不会触发该输入法；
- 微信输入法、豆包（右 Alt）的默认热键不变。

## 兼容性

- 无破坏性变更，已有配置照旧读取；
- 如果你之前**没有**自定义过 Chatterfly 的热键（即依赖旧默认 `Ctrl+Win`），升级后需要自己
  点选一次；已经在设置里配置过自定义热键的用户不受影响。
