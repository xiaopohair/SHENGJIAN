# 声键 0.9.0 发布说明

日期：待发布

> 本文件在 `v0.9.0` tag 推送时由 release workflow 逐字发布（`body_path`）。


## 不兼容变更

本次有 3 处会让**已有配置或旧版本数据**不再按老路径生效，升级前请对照检查。

### 1. 语音输入工具清单改名

- 旧：`config/voice-tools.json`
- 新：`config/voice-tool-presets.json`

安装目录下的 `resources/config/voice-tools.json` **不再被读取**。如果你在已装机器上
直接改过这个文件（自定义工具名、默认热键、输入法 TSF 身份等），升级后请把文件改名成
`voice-tool-presets.json`；不处理也不会崩，程序会回退到安装包内嵌的默认清单，行为等同于没改过。

### 2. 推荐按键方案的源目录改名（仅仓库侧）

- 旧：`config/button-profiles/`
- 新：`config/recommended-button-profiles/`

只影响仓库里维护推荐方案的人（以及脚本 `pnpm config:build` / `config:check` 的默认目录），
已安装用户不受影响——运行时装进包里的仍然是聚合文件 `config/button-profiles.json`。

### 3. 移除「旧版单文件方案库」的一次性导入

0.6.0 起，首次启动会把 0.5.0 之前留下的单文件方案库（`button-profiles.json`）导入新的
`profiles/` 目录布局，并把旧文件改名成 `.migrated.bak`。这段兼容逻辑已删除。

- 影响范围：只在「从 **0.4.x 或更早** 直接跳到本版本」的机器上才会体现
- 表现：旧文件不再被自动导入，程序从默认方案开始；旧文件**不会被删除**，仍在原处
- 手动恢复：把该文件按新布局手工整理，或用 `pnpm config:import-profile` 转成推荐方案
- 已经跑过 0.5～0.8 任意版本的机器：早在当时就完成了导入，本次无影响

## 推荐方案集合更新

`config/button-profiles.json` 的 `bundleVersion` 升到 `2026.11.4`，按键页会提示「有更新」：

- 新增 5 条推荐方案：Claude Code 按键、Codex 按键、微信按键、WorkBuddy 按键、WPS 演示放映
- 删除示例方案 `preset.netease.controls`（网易云音乐示例）与 `preset.desktop.shortcuts`（桌面快捷键示例），两者都只用于早期功能演示
- 推荐方案的 `appTargets` 现在一律写 exe 文件名（如 `wechat.exe`），不再写应用预设 id

## 变更

**常用语（本轮新增）**

- 设置 → 常用语 维护一份文本列表；把遥控器按键绑成「常用语」动作后，按下即弹出浮层，
  ↑/↓ 选择、OK 插入、返回/Menu 关闭。浮层是**不抢焦点**的原生窗口，打开时不会打断正在输入的窗口
- 面板打开期间这些按键在手势识别之前被认领，不产生单击/双击/长按，也不写持久绑定
- 数据存 `%LOCALAPPDATA%\Shengjian\common-phrases.json`；名称与文本都为空的行不会落盘
- 设置页的常用语表格与按键方案页的表格视图同一套骨架（卡片、表头、行分隔、键帽序号）；字数统计
  并入内容输入框，随控件一起浮起展开

**连接与设备**

- 连接页重做：设备卡改 hero 结构，扫描列表按相对时间标出「已连接 / N 分钟前 / 从未连接」，
  型号按设备令牌记忆（断开后重扫仍能认出是哪一支），增益显示「实际生效」值
- 新增「忘记设备」：先断开再解除 Windows 配对，之后扫描不到这支
- 未连接时按遥控器任意键自动连回上次那台；用户主动「断开」后不再自动连（重启仍会尝试）
- 设备测试面板：顶栏命令面板可随时打开「语音测试 / 按键测试」，只读、不写设置；语音落字用
  应用内原生测试板，输入法能正常落字、主窗口不重载
- 顶栏新增「监听中 / 已暂停」胶囊，可随时暂停/恢复按键监听（语音与蓝牙连接不受影响）

**设置与外壳**

- 设置页改为分区导航：外观与语言 / 常用语 / 音频及语音 / 启动与窗口 / 数据与诊断 / 高级；
  全按键支持服务的安装与卸载都收口到这里
- 托盘：单一 32px 应用图标（自带深色底板，不再分主题两套），tooltip 显示按键方案 / 遥控器 /
  输入法 / 电量四行状态
- 启动画面换成 76px 圆角应用图标 + 深色投影
- 安装包支持覆盖升级：升级前停掉 RC003 助手的计划任务，仍被占用的旧 exe/dll 改名挪开并在下次
  重启时清理
- 首次配置重做：按键清单按型号过滤（ARN9 没有 TV 键）、语音输出只允许 VB-CABLE、会丢弃注入键
  的输入法（如豆包）明确提示必须开启全按键支持
- 弹窗统一到 `DialogShell` + `useModalFocus`（遮罩、焦点圈定、Esc 与遮罩关闭只有一份实现）

**文案与术语**

- 「按键增强 / 增强捕获」统一改称「全按键支持」，中英文词条同步
- 默认方案名「默认」跟随界面语言；README 标题改为中文，品牌图标统一使用深色底应用图标

## 修复

- **常用语面板关闭后实体键盘方向键失效**：点击浮层走的是 `WM_LBUTTONUP → WM_CLOSE →
  DestroyWindow`，绕过了宿主的关闭流程，导致「面板打开」标记与键门控遮蔽掩码一直挂着，
  低层键盘钩子继续吞键直到应用退出。现在 `WM_DESTROY` 回调宿主的 `close_panel` 复位
- **常用语面板指针显示为「运行中」**：窗口类没有设置游标、也不处理 `WM_SETCURSOR`，指针沿用了
  上一个窗口的状态。补 `IDC_ARROW` 类游标并显式处理 `WM_SETCURSOR`
- 常用语表格：内容格聚焦时向下漂移（焦点态绝对定位后单元格塌成 0 高度被垂直居中）、字数统计
  浮在输入框外面、操作列表头未居中
- 点「添加」但不输入内容会被自动保存，切走再回来仍在；现在空白行不落盘
- 关于页能力清单仍用「增强捕获」；顶栏搜索的 `focusout` 延迟定时器在卸载后仍会触发
