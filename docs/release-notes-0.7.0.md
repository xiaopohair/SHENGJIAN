# 声键 0.7.0 发布说明

日期：2026-11-14

`0.7.0` 的主题是**首次配置可靠性**与**可配置内容**：把长期依赖的 VB-CABLE 虚拟声卡
从“隐式假设”变成显式检测与引导；首次向导改为每一步必须测试通过才能继续；
同时把推荐应用、推荐按键方案、推荐宏与语音输入工具全部改为可编辑的配置文件，
并扩展了系统动作网格。

## 亮点

- **VB-CABLE 依赖检测（首次配置硬阻断）**
  - 新增 `audio_dependency_status`：检测可用 CABLE 端点，并在端点不可用时查注册表
    （`VB-Audio\Cable` / Uninstall `VB:VBCABLE`，兼容 32/64 位），返回
    `ready / disabled / missing`、建议端点与官方安装地址
  - 首次向导第 3 步：
    - 检测到 VB-CABLE：不显示任何依赖提示，直接进入语音测试
    - 未检测到：提示下载 VB-CABLE（打开官网）+「重新检测」，检测通过前不能继续
    - 已安装但设备未启用：提示去 Windows 声音设置启用/重启，同样提供下载入口
  - 设置页「音频及语音」新增 VB-CABLE 状态行与下载/重新检测入口；设备下拉无 CABLE 时
    给出内联提示；已保存端点失效时提示重新选择
  - 健康检查把旧的「有任意音频设备就算通过」改为「虚拟音频设备」：只有 VB-CABLE ready
    才通过；设备名过长时折行，不再溢出
  - 安装入口只打开 VB-Audio 官网，不在应用内静默安装第三方驱动

- **首次向导每一步必须测试通过**
  - 第 2 步「扫描并连接」：未连接遥控器不能下一步
  - 第 3 步「测试语音键」：必须收到成功语音事件才能下一步；失败提示重试
  - 第 4 步「检测遥控器按键」：必须检测到全部按键才能下一步
  - 删除「稍后连接」「跳过语音测试」「跳过按键测试」等跳过入口，主按钮统一为「下一步」
  - 第 4 步说明明确：返回键和音量键需要安装按键增强服务并开启才能使用；首次安装会请求
    管理员授权

- **系统动作扩展**
  - 宏编辑器与按键方案的系统动作改为「图标 + 文字」卡片网格，一行 5 个
  - 动作补齐到 9 个：音量 +/−、静音、播放/暂停、上一曲、下一曲、显示桌面（Win+D）、
    切换任务（Alt+Tab）、退出（Esc，键帽 + 中文「退出」/英文「Escape」）
  - 宏里保存真实组合键（显示桌面 = `win` + `d`，切换任务 = `alt` + `tab`）；
    按键方案存语义 id，由执行层展开；组合动作不参与按住连发
  - 兼容旧数据：已有 `system-action` 配置无需迁移

- **推荐内容配置化**
  - 新增仓库根目录 `config/` 配置：`app-presets.json`、`voice-tools.json`、
    `button-profiles.json`、`recommended-macros.json`，构建时复制进安装包资源；
    安装目录内可直接修改，重启生效
  - 内置只读推荐按键方案：可查看、复制后使用，不会覆盖用户方案
  - 推荐宏接入运行时与按键方案动作下拉，支持嵌套运行
  - 「打开应用」选择器：应用目录 + 已安装应用 + UWP/AppsFolder，显示应用图标；
    保存时按应用身份规范化，旧式目标可一键修复

- **语音输入与 IME**
  - 新增 Chatterfly 支持（IME 切换与观测）
  - Chatterfly 的 TSF 身份改为配置驱动，显示名自动发现
  - 语音输入工具列表支持配置文件维护，不再硬编码

- **健康检查与体验修复**
  - 「近期错误行」只统计本次运行进程的日志，并按秒合并同一次失败的多行
    （一次 BLE 超时不再显示成 4 条）
  - 健康检查标签改为面向用户的「按键增强服务」「虚拟音频设备」「音频输出设备」
  - 修复宏动作参数区切换动作类型时的抖动、宏标题误点、Toast 位置、更新横幅等问题
  - 首次向导、宏编辑器、按键方案的多处文案与布局统一

## 安装

Release 资产：

```text
shengjian_0.7.0_x64-setup.exe      安装包（NSIS，未签名）
shengjian_0.7.0_x64-portable.zip   便携版（免安装 zip）
SHA256SUMS                         两个产物的 SHA-256
manifest.json                      安装包大小与 SHA-256
portable-manifest.json             便携版大小与 SHA-256
```

下载后可用随包的 `SHA256SUMS` 校验：

```powershell
Get-FileHash shengjian_0.7.0_x64-setup.exe -Algorithm SHA256
# 与 SHA256SUMS 中对应的行比对
```

校验值以 Release 里的 `SHA256SUMS` 与 `manifest.json` 为准，本文不硬编码。

安装包未签名，Windows SmartScreen 可能提示；首次安装按键增强服务需要一次 UAC。
覆盖安装会保留设置、方案、宏、语音记录与日志。

## 升级说明

- 覆盖安装会保留 `%LOCALAPPDATA%\Shengjian` 下的全部用户数据
- 依赖 VB-CABLE 才能听到远程语音；升级后首次进入向导若未安装会提示下载安装，
  安装完成点「重新检测」即可继续
- 推荐应用/方案/宏来自安装包内的 `config/`，不覆盖用户已有配置；推荐方案需复制后使用
- 旧版 `system-action`、方案与宏数据结构保持兼容，无需手动迁移

## 已知限制

- 仅 Windows x64；未提供 ARM64 包
- 0.7.0 为未签名发布包
- 无自动更新
- 虚拟声卡检测当前只识别 VB-CABLE；其他虚拟声卡（VoiceMeeter 等）暂不自动识别，
  可手动选择音频输出设备
- 首次向导要求遥控器实际连接、语音测试成功、全部按键检测通过，缺一不能进入下一步
- 推荐方案为只读，修改需先复制为普通方案
- 「打开应用」列表依赖开始菜单/AppsFolder 扫描，个别便携应用可能不在列表中，
  可用「选择文件」手动指定
