# 声键 0.6.0 发布说明

日期：2026-11-12

`0.6.0` 的主题是**方案按设备型号隔离**：按键方案不再是全库共用一份，而是每个遥控器型号
各有自己的方案列表与默认方案。同时新增对 ARN9（小米蓝牙语音遥控器普通款）的完整支持，
三款小米遥控器现在都有各自的产品图与实测热区。

## 亮点

- **方案按设备型号隔离**
  - 每个型号有独立的方案列表；切到哪台遥控器就只看得到那台的方案，互不干扰
  - 「全局方案」语义更正为「默认方案」，且**每个型号一份**（外加一份「通用」兜底）：
    同型号的其他方案继承本型号默认方案，默认方案自身再继承出厂映射
  - 默认方案名称固定为「默认」，不可删除、不关联应用；界面不再显示无意义的「激活」开关
  - 存储改为 `<型号>-<名称>-<id 尾段>.json` 一方案一文件，索引升到 `schemaVersion 5`
  - 旧数据迁移：全部归给 RC003，原「全局方案」升格为 RC003 默认方案；迁移前把整个方案目录
    备份为 `profiles.backup-<时间戳>`
  - 新增「记住上次型号」：未连接遥控器时按上次连过的型号展示方案

- **新增设备：ARN9（小米蓝牙语音遥控器）**
  - 按 GATT 型号号 `0x2A24 = ARN9` 识别为**独立型号**，不再被误当成 RC003
  - 新增设备档案 `profiles/xiaomi-arn9.json`（真机探测得出：VID 10007 / PID 12984、
    9 个 GATT 服务、ATVV 语音服务、无 TV 键）
  - 按键布局为 11 键（去掉 TV），产品图与热区按实拍图单独标定
  - 界面显示正式名称「小米蓝牙语音遥控器」
  - 已验证：ATVV 语音链路（2.49 秒会话、36480 采样、peak −2.7 dBFS 无削波）、
    导航六键、音量 ± 与返回键（增强捕获 `0x80`/`0x81`/`0xF1`）

- **三款遥控器各自的产品图与热区**
  - RC003 / RC001 / ARN9 都使用自己的产品图，热区坐标按各自图片实测标定（不是目测估算）
  - RC001 与 RC003 产品图已统一到同一画布与机身尺寸，两者共用同一套热区表
  - 配对帮助新增 ARN9 型号标签；三款统一使用厂商正式名称（不再写英文代号）；
    ARN9 因无 TV 键，不显示「先按 TV 完成初始化」提示

- **配对页切换型号不再抖动**
  - 三张产品图常驻 DOM、只切换显隐，避免换 `<img src>` 导致的空白帧闪烁
  - 按型号归一化产品主体显示尺寸，切换标签时不再有缩放跳变

- **修复**
  - 「扫描设备」不再把仍在工作的连接降级为「已断开」（此前扫一次就会显示未连接，
    而蓝牙链路其实还活着）
  - 连接页点某台设备的「连接」时，只有那一行显示「连接中」，不再全列表都显示
  - 按键方案工作台的设备胶囊改为显示产品正式名（型号识别不出来时退回蓝牙名）
  - 首次运行补上旧版单文件方案库（`button-profiles.json`）的一次性导入，
    避免从更老版本升级时方案被静默丢弃

- **其他**
  - 「关于 → 支持的遥控器」中 RC003 的 macOS 状态由「已支持」改为「计划中」
    （本仓库是纯 Windows 实现）
  - 记录 Apple Siri Remote 的适配评估结论（暂不适配，详见 `docs/apple-siri-remote.md`）

## 安装

Release 资产：

```text
shengjian_0.6.0_x64-setup.exe      安装包（NSIS，未签名）
shengjian_0.6.0_x64-portable.zip   便携版（免安装 zip）
SHA256SUMS                         两个产物的 SHA-256
manifest.json                      安装包大小与 SHA-256
portable-manifest.json             便携版大小与 SHA-256
```

下载后用随包的 `SHA256SUMS` 校验：

```powershell
Get-FileHash shengjian_0.6.0_x64-setup.exe -Algorithm SHA256
# 与 SHA256SUMS 中对应的行比对
```

校验值以 Release 里的 `SHA256SUMS` 与 `manifest.json` 为准，本文不硬编码，
避免与实际上传的构建产物不一致。

安装包未签名，Windows SmartScreen 可能提示；首次安装 helper 需要一次 UAC。
覆盖安装会保留 `%LOCALAPPDATA%\Shengjian` 下的设置、方案、宏、语音记录与日志。

> 便携版请解压到普通目录（桌面、D 盘目录等）后运行，不要直接在受限目录里运行。

## 升级说明

- 覆盖安装会保留 `%LOCALAPPDATA%\Shengjian` 下的设置、方案、宏、语音记录与日志
- **方案存储会自动升级到 `schemaVersion 5`**：首次启动时把旧方案全部归到 RC003，
  原「全局方案」变成 RC003 的默认方案；升级前会把方案目录备份为
  `%LOCALAPPDATA%\Shengjian\profiles.backup-<时间戳>`，出问题可从备份恢复
- 从更老版本（方案还存放在单个 `button-profiles.json` 里）升级时，首次启动会自动
  导入那些方案并把原文件改名为 `button-profiles.json.migrated.bak`
- 如果你的遥控器是 ARN9（普通款，无 TV 键），升级后会被识别为「小米蓝牙语音遥控器」，
  并拥有独立的方案列表（初始为一份空的默认方案）

## 已知限制

- 仅 Windows x64；未提供 ARM64 包
- 0.6.0 为未签名发布包
- 无自动更新
- ARN9 的 macOS 支持未验证；RC001 仍是 `research` 状态，不进入运行时型号匹配
- ARN9 与 RC003 在 Windows 蓝牙列表里广播名完全相同，只能靠 GATT 型号号区分
- Apple Siri Remote 暂不适配（Windows 侧拿不到语音，详见 `docs/apple-siri-remote.md`）
- 「聚焦应用输入框」需要先在按键方案里配置过对应应用的聚焦方式，否则步骤会报缺少依赖
