# 声键 0.9.7 发布说明

日期：2026-11-19

> 本文件在 `v0.9.7` tag 推送时由 release workflow 逐字发布（`body_path`）。

## 修复：按键测试不再触发方案动作

0.9.6 的设备测试和首次配置向导「按键测试」存在一个影响使用的问题：测试时按遥控器
按键，除了被测试面板记录外，还会执行当前按键方案的真实动作（快捷键、宏、鼠标等），
导致测试过程被弹窗、快捷键或宏打断。

0.9.7 为按键测试增加了只读模式：

- 按键边沿与手势仍然照常上报，测试清单和高亮正常；
- core 与平台注入层都不执行当前方案动作；
- 关闭测试面板、离开首次配置的按键步骤或结束向导后自动恢复；
- 与「暂停按键监听」的暂挂状态合并，不会互相提前解除。

## 自动更新

- **0.9.6 用户可以直接在应用内升级到 0.9.7。** 打开「设置 → 软件更新」检查更新，
  下载并校验完成后点「重启并安装」即可。
- **0.9.5 及更早版本没有更新器**，仍需先手动安装一次 0.9.6；从 0.9.6 起才能自动升级。
- 便携版与开发版不支持应用内升级，请手动下载新版本压缩包。

## 说明

- 更新仍然只覆盖 NSIS 安装版；更新包按 Release `manifest.json` 的 `sizeBytes` /
  `sha256` 校验，安装前由用户确认。
- 安装包未启用签名时仍可能出现 SmartScreen 提示；校验值以 Release 内的
  `SHA256SUMS` 为准，本文不硬编码哈希。
- 设置、方案、宏与历史继续保存在 `%LOCALAPPDATA%\Shengjian`，升级后保留。

## Release 资产

- `shengjian_0.9.7_x64-setup.exe` — NSIS 安装包（支持后续自动升级）
- `shengjian_0.9.7_x64-portable.zip` — 便携版（手动更新）
- `manifest.json` / `portable-manifest.json` — 大小与 SHA-256
- `SHA256SUMS` — 两个产物的校验和
- 许可证与第三方声明文件
