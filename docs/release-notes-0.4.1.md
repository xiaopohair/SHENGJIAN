# 声键 0.4.1 发布说明

日期：2026-11-11

`0.4.1` 是一轮界面修复与响应式整顿：修好按键方案页「新建后看不到编辑区」、连接页未连接设备时的多余区块、宏页编辑标题行的分隔线与高度跳动，并把全仓不可达的响应式断点收敛为可达档位。

## 修复

- **按键方案页**
  - 没有方案时导航工具栏不再隐藏：导入 / 导出 / 新建常驻，导出按钮在无方案时禁用
  - 点「新建」后立即显示完整编辑区（此前只出现标题行，需要保存后才出现编辑区）
  - 没有方案且没有草稿时，隐藏标签栏与「工作台 / 表格视图」切换
  - 新建草稿时标签栏显示「+」占位标签，取消后回到空状态
  - 工具栏操作按钮改为右对齐
  - 修正新建标签「+」徽章被选中态样式覆盖的问题

- **连接页**
  - 未连接设备时不再显示「当前设备覆盖」区块（含「连接设备后可配置…」占位提示）；连接后照常出现，并带设备名称提示

- **宏页**
  - 编辑标题行下方补 1px 分隔线，与按键页一致
  - 「未保存」标记改为内联在名称输入框右侧：标题行高度恒定（43px），分隔线不再随保存状态上下移动

- **窗口**
  - 默认高度 720 → 920，最小高度 640 → 880：未连接设备时，连接页「发现的设备」区块可以完整显示

## 响应式

- 窗口最小宽度为 1200，此前全仓 32 处 `max-width` 小于 1200 的断点在桌面壳里永远不会触发（死代码）。本次统一收敛为三档可达断点：
  - `<=1400`：中等档（动作 / 绑定网格列数压缩）
  - `<=1320`：整页级分栏改单列（语音页两个区块、About hero、配对弹层、方案矩阵等），默认 1280 窗口即生效
  - `<=1260`：紧凑档（表单单列、行布局重排、页头 / 工具栏堆叠、内边距收窄）
- 语音页「语音输入工具」「语音测试」两个区块改为上下排列
- 删除与合并重复、自相矛盾的媒体查询；同步更新 `docs/ui-design-system.md` 的响应式规范

## 其它

- 方案标签的滚动定位改为可选调用，避免缺少 `scrollIntoView` 的环境报错
- 新增按键方案页 5 个前端回归用例（空状态工具栏、首建立即显示编辑区、已有方案时新建、取消新建、保存后编辑区保持）

## 安装

Release 资产：

```text
shengjian_0.4.1_x64-setup.exe      安装包（NSIS，未签名）
shengjian_0.4.1_x64-portable.zip   便携版（免安装 zip）
SHA256SUMS                         两个产物的 SHA-256
manifest.json                      安装包大小与 SHA-256
portable-manifest.json             便携版大小与 SHA-256
```

下载后用随包的 `SHA256SUMS` 校验：

```powershell
Get-FileHash shengjian_0.4.1_x64-setup.exe -Algorithm SHA256
# 与 SHA256SUMS 中对应的行比对
```

校验值以 Release 里的 `SHA256SUMS` 与 `manifest.json` 为准，本文不硬编码，
避免与实际上传的构建产物不一致。

安装包未签名，Windows SmartScreen 可能提示；首次安装 RC003 helper 需要一次 UAC。覆盖安装会保留 `%LOCALAPPDATA%\Shengjian` 下的设置、方案、宏、转写历史与日志。

## 已知限制

- 仅 Windows x64；未提供 ARM64 包
- 0.4.1 为未签名发布包
- 无自动更新
- 「聚焦应用输入框」需要先在按键方案里配置过对应应用的聚焦方式，否则步骤会报缺少依赖
- RC001 / ARN9 设备身份映射仍为 deferred
