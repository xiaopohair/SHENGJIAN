# 声键 0.9.4 发布说明

日期：2026-11-19

> 本文件在 `v0.9.4` tag 推送时由 release workflow 逐字发布（`body_path`）。

## 新增：Google Chromecast TV Remote

支持 Google 的 Chromecast 语音遥控器（2020/2021 款）：

- 连接页显示为 **Google Chromecast TV Remote**（型号 `CHROMECAST`）；
- 14 个按键全部可用：确定 / 返回 / 方向 / 主页 / 电源 / 音量+ / 音量− / 静音 /
  YouTube / Netflix / 信源；助理键是硬件语音键，按住即说话；
- 语音走 ATVV，实测 16 kHz 满速；
- 默认按键映射（连上即生效）：确定→回车、返回→Esc、方向键、主页→Ctrl+T、
  电压→F11、音量±/静音→系统音量；YouTube / Netflix / 信源默认不绑定。

> 这台设备的按键报告不出现在系统的 Raw Input 层，需要后台组件（helper）读取后转发。
> 首次连接时按提示完成一次管理员授权即可。

## 变更：小米三款的默认方案补齐按键

RC001 / RC003 / ARN9 的默认方案现在带：方向键 → `↑↓←→`、OK → `Enter`、
返回 → `Esc`、音量± → 系统音量。Home / 菜单 / TV / 电源保持未绑定，
需要的话在「按键」页自行配置。

## 修复

- **一次按键执行两遍**：边沿同时被 app 层与注入层执行，静音表现为「按下即静音、随即取消」，
  回车会打两个。现在由注入层统一执行。
- **动作转换漏项**：注入层支持 8 种动作，转换器只映射了 3 种，滚动 / 鼠标 / 运行宏 /
  打开应用 / 常用语 / 聚焦输入框会被静默丢弃。已补全并加回归测试。
- **型号基线不生效**：映射重算的判重键不含设备型号，切换设备后不重算；
  合成只遍历小米 12 键，型号布局里的键（如静音）绑定会静默失效。均已修复。
- **语音速率误报 `degraded`**：分母用了会话墙钟，把起步延迟与松手后的尾巴都算进去，
  16 kHz 被算成 9~11 kHz。改为按首帧→末帧计算。
- **安装包可能带旧 helper**：`pnpm build:installer` 之前不构建 helper，现已在打包前先构建。

## 界面

- 连接页使用 Chromecast 线稿图；
- 配对指南新增 Google 机型（配对手法：同时按住「返回」和「主页」约 3 秒，
  蓝牙列表中的名字是 `Chromecast Remote`）；
- 按键方案页支持 Chromecast 产品图与 14 个热区，表格视图补齐静音 / YouTube /
  Netflix / 信源的键帽字形；
- 补齐上述文案的英文翻译。

## 升级提示

- 后台组件（helper）随安装包更新，升级后若未生效，到 **设置 → 音频及语音 →
  遥控器 → 全按键支持服务** 点一次「更新」；
- 已保存的小米方案不受影响；新增的默认绑定只在「默认方案」里，且不会覆盖你
  自定义过的方案。
