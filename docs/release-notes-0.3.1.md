# 声键 0.3.1 发布说明

日期：2026-11-09

`0.3.1` 重做了按键方案工作台，并补齐按键级连发、表格视图与方案导航体验。

## 亮点

- **按键方案工作台**
  - 遥控器产品图热区选键，单击/双击/长按分别编辑
  - 恢复 12 个可编辑按键（含 TV、菜单）
  - 新增表格视图，按键与三种手势一屏对照
  - 表格动作单行居中显示，已配置按键使用强调色
  - 表格行增加上边框，去掉内部滚动条

- **按键级按住连发**
  - 连发从方案级改为按键级，单击/长按二选一
  - 只对可重复动作显示连发设置
  - 禁用、继承、打开应用、组合快捷键等动作自动隐藏并清理连发
  - 保持固定重复间隔：返回键 50ms，其他键 100ms

- **方案导航**
  - 方案名称改为单行，选中加粗，未选中正常字重
  - 图标改为状态圆点：未选中灰色、选中绿色、激活蓝色
  - 激活方案不再显示边框和尾部圆点
  - 方案过多时导航横向滚动，右侧新建/导入/导出固定不换行
  - 导航下方与“当前方案”工具栏合并为一条上边线

- **方案设置与鼠标动作**
  - 语音输入工具新增说明：设备有单独覆盖设置时，以设备设置为准
  - 选项文案调整为“使用设备覆盖设置或全局设置”
  - 鼠标动作支持右键点击
  - 切换单击/滚动/移动时保留方向与数值，滚轮使用“格”、移动使用“px”

- **清理**
  - 移除“从模板新建”入口与残留内置模板
  - 方案设置去除全局按住连发
  - 方案设置按钮上方多余横线移除
