# 声键 0.8.0 发布说明

日期：2026-11-14

`0.8.0` 的主题是**录入方式与页面结构**：组合键从“键盘直接采集”整体改为“弹出点选”，
绕开输入法抢键这个长期问题；宏库支持单文件 / 多文件导入导出并给出真实进度；
连接页与宏页的导航重做，把重复的按钮和区块收敛掉。

## 亮点

- **组合键一律点选录入（不再键盘直接采集）**
  - 语音热键、宏动作快捷键、按键动作快捷键全部改为弹出面板：点修饰键 + 主键即可组合，
    不再要求“按下组合键”。原因是输入法（Chatterfly 的 Ctrl+Win 是典型）和 Shell 会在
    我们的钩子之前截走半个组合，现场表现是“按了没反应 / 只录到一半”
  - 修饰键区分左右（左/右 Ctrl、Shift、Alt、Win），面板里统一键帽样式，
    当前组合也按“一个按键一枚键帽”显示
  - 这条约定写进 `docs/ui-design-system.md` §5 第 20 条，避免以后又改回采集

- **宏库导入导出：单文件 / 多文件**
  - 导出：整库打包成一个 JSON，或每个宏一个文件（文件名取宏名，重名自动加序号）
  - 导入：整库替换，或多选文件后按 `macroId` + `version` 合并（同 ID 同版本跳过、
    同 ID 新版本覆盖、新 ID 追加），结束后给出「新增 / 更新 / 跳过」计数
  - 按条推进时有真实进度条（`done / total`），单次调用只给不定态，不编百分比；
    面板与「按键方案导入导出」同一套骨架（头部徽标、分段控件、双栏、页脚操作）

- **宏页导航重构**
  - 编辑工具栏整体删除，动作统一到页面导航栏：**试运行 / 保存 / 添加 / 属性 / 更多操作**
  - 复制宏、删除宏、导入导出收进「更多操作」菜单；取消按钮移除
  - 新建宏**直接落盘成草稿**，标签栏立即可见；未保存时切换宏 / 离开页面会提示
  - 步骤列表：整行可拖，拖动时有跟随指针的鬼影与强调色插入线，贴近边缘自动滚动；
    行改成带边框的卡片，行与行一眼可分

- **连接页重做**
  - 设备信息卡：自定义设备昵称作标题、`产品名 · 型号` 副标题、电量 / 已连接时长 / 固件
    三项指标（hover 有说明）、蓝牙 / 语音 / 按键增强三枚状态胶囊、顶部强调色渐变边
  - 「设置」打开右侧设备设置抽屉（设备名称、独立音频开关、增益、语音输出设备、
    语音输入工具），原先平铺在页面上的「当前设备覆盖」卡片移入抽屉
  - 断开后卡片不再变形抖动：继续显示同一张产品图与全部标签，只是值变为「未知」
  - 顶栏：设备名改成胶囊；命令入口恢复成输入框外观（提示「搜索页面和命令」+ `Ctrl K`）；
    品牌只保留在侧栏，标题栏不再重复显示图标与名称
  - 删除连接页的「增强捕获」区块，按键增强开关统一留在「设置 → 音频及语音」

- **界面规范与其他**
  - Toast 反馈标准落地：层级升到 400（不再被弹窗遮挡）、同时最多 3 条、同消息 5s 去重、
    补 toast 与 ToastHost 测试；按键增强安装这类长流程改用页内 Notice
  - 导入导出统一「能按条计数才给百分比」的进度语义（`ui/TransferProgress`）
  - 新方案未指定名字时默认取程序名；设置页分组「按键增强」改名「遥控器」；
    关于页「组件与许可」里的 `RC003 helper` 改为「按键增强（RC003 helper）」
  - README：顶部品牌区居中、换成黑色底纯图标版应用图标，中英文切换链接双向可用

## 修复

- 修复步骤列表拖动时没有任何过程反馈（只有源行半透明，看不出落点）
- 修复连接页断开瞬间图像换成兜底线稿、右侧操作区塌陷导致的高度跳动
- 修复「更多操作」菜单 hover 缺少强调色（排查确认不是内联样式，是 hover 只给了中性底色）
- 修复组合键录入偶发零边沿：录入起始的 preheld 扫描把半按残留的标记键当成用户按键

## 升级说明

- 覆盖安装即可，用户数据（`%LOCALAPPDATA%\Shengjian`）保留
- 已保存的语音热键 / 动作快捷键不需要重新录入：旧的组合仍然有效，只是今后想改会在点选面板里改
- 设备昵称是新字段，留空则继续使用遥控器广播名，不影响已有配置

## 已知限制

- 不包含自动更新器，需要手动下载安装包覆盖安装
- 按键增强服务仍需管理员权限安装，安装 / 更新 / 卸载在「设置 → 音频及语音」统一管理
- 信号强度（dBm）暂未显示：Windows BLE 侧没有稳定可用的 RSSI 通道
