# 声键 0.4.0 发布说明

日期：2026-11-10

`0.4.0` 重做了宏编辑器，并让「打开应用」真正支持任意程序路径。

## 亮点

- **宏编辑器重做**
  - 三栏布局：步骤列表、当前步骤动作、动作参数分栏呈现，去掉左右两侧的宏库与版本面板
  - 步骤列表直接显示快捷键文字与执行结果（完成/失败 + 耗时），拖动把手可调整顺序
  - 上移/下移/添加按钮移到步骤标题下方右侧，用图标按钮呈现
  - 动作图标按类型着色，便于在列表里快速区分
  - 新增宏属性抽屉：名称与说明集中编辑，标题区只保留名称
  - 标题前缀「编辑宏：」，页面补齐 `Macros` 英文小标
  - 保存后编辑器保持打开；保存错误在按钮下方右对齐就地显示
  - 手势/按键采集统一为「捕获」按钮，不再需要手输组合键文本

- **打开应用支持任意程序**
  - 原生可执行文件名（如 `notepad.exe`）会依次按 App Paths 注册表、`PATH`、开始菜单快捷方式解析出真实路径再启动
  - 「选择程序」保存完整路径，不再只存文件名
  - 修复此前非预设程序一律报「未知预设应用」、0ms 失败的问题

- **等待应用运行**
  - 动作更名为「等待应用运行」，字段改为「启动成功标志」（进程运行 / 窗口可见）
  - 目标、启动标志与步骤超时合并到同一行

- **系统动作改为下拉选择**
  - 固定 7 个键：音量 +/−、静音、播放/暂停、上一曲、下一曲、Esc，不再用任意组合键录入

- **按键方案页**
  - 动作标签在窄窗口下一行 3 个
  - 方案导航改为分段标签 + 序号徽章，激活方案带角标
  - 「激活」改为开关并显示当前状态，与「自动应用」标签同行
  - 「当前方案」改为「编辑方案：」，方案名放大
  - 属性按钮改为纯图标；抽屉「完成」按钮右对齐
  - 导入/导出按钮补上文字

- **清理**
  - 移除宏的版本概念（保存即覆盖，不再产生版本历史）
  - 移除「可运行」统计、`#1 / 5` 序号紧跟标题
  - 快捷键不再预填 `Ctrl + N`，已设置的快捷键可一键清除

Release 资产：

```text
shengjian_0.4.0_x64-setup.exe
大小：11355370 bytes
SHA-256：C95DEE346C0AA9DA295151741138B5753D31956B479613FFBBE8E885E94CE31B

shengjian_0.4.0_x64-portable.zip
大小：14823199 bytes
SHA-256：7385B4D9446B29039CE43FDA8F31870B401635F957859219DA573F0902D3960E
```

下载后建议用随包的 `SHA256SUMS` 自行校验：

```powershell
Get-FileHash shengjian_0.4.0_x64-setup.exe -Algorithm SHA256
```

安装包未签名，Windows SmartScreen 可能提示；首次安装 RC003 helper 需要一次 UAC。覆盖安装会保留 `%LOCALAPPDATA%\Shengjian` 下的设置、方案、宏、转写历史与日志。

## 已知限制

- 仅 Windows x64；未提供 ARM64 包
- 0.4.0 为未签名发布包
- 无自动更新
- 「聚焦应用输入框」需要先在按键方案里配置过对应应用的聚焦方式，否则步骤会报缺少依赖
- RC001 / ARN9 设备身份映射仍为 deferred
